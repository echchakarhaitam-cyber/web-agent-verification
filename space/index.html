Can you trust a small web agent when it says "done"?

A local language-model agent (Qwen2.5 0.5B or 1.5B) was given 15 tasks on MiniWoB++ web pages, 20 times each. At the end it reported success or failure; the page itself recorded whether the task was really done. This page replays the 600 recorded episodes (the models are not running here): pick one to see what the agent did, what it claimed, and the truth.

Code, protocol and full analysis: github.com/echchakarhaitam-cyber/web-agent-verification.
